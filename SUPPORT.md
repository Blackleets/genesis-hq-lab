# Support

Genesis HQ is a research project, not a managed trading service.

## Where to ask

### Bug or reproducible regression

Open a GitHub issue using the bug template.

Include:

- command or path that fails;
- expected behavior;
- actual behavior;
- redacted logs;
- whether an economic/safety gate is affected.

### Research proposal

Use the research-proposal issue form.

A strong proposal states a falsifiable hypothesis, data provenance, economic assumptions and validation plan.

## What support cannot validate for you

A GitHub answer cannot make a strategy profitable or convert paper evidence into live-capital proof.

Genesis intentionally distinguishes:

- software correctness;
- research validity;
- economic edge;
- operational readiness.

Those are separate claims.

## Security

For secrets, signing authority, wallet access or active exploit details, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.
